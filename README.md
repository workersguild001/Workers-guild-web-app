# The Workers Guild - Production Terminal Suite (v0.1)

The definitive, AI-native administrative terminal for the modern trade labor force. This repository contains the complete frontend infrastructure for **The Workers Guild**, designed with a "6th-grade simple" industrial aesthetic and integrated with Supabase and PayPal.

## 🚀 Deployment

1.  **Frontend**: Deploy these files to Netlify, Vercel, or GitHub Pages.
2.  **Backend**: Execute the SQL schemas found in `GUILD_DATABASE_SCHEMA.sql` within your Supabase SQL Editor.
3.  **Authentication**: Configure Supabase Email Auth and set redirect URLs to `https://workersguild.store/recruitment.html`.

## 📁 File Structure

### Public Gateway
- `index.html`: Main landing page with a gated "Gateway Access" entrance and Supabase waitlist.
- `404.html`: Comedic, industrial-themed error page.
- `terms.html`: Doctorate-level zero-liability legal documentation.

### Authentication Terminals
- `signin.html`: Secure gateway for returning craftsmen.
- `signup.html`: Onboarding terminal with integrated TOS acceptance.
- `recovery.html`: Account recovery and security protocol.

### The Guild Network (gateway.html)
- `gateway.html`: The central hub linking all operational networks.
- `recruitment.html`: Affiliate Master Console featuring the permanent "Guild Pass" QR code.
- `profile.html`: Social-style craftsman dashboard with OSRS-inspired leveling (1-99).
- `skills.html`: The master Skills Matrix tracking 14 trade categories.
- `payouts.html`: Financial gateway for PayPal fund withdrawals.

### Job Poster Command
- `client-dashboard.html`: Command center for hiring parties and applicant tracking.
- `post-job.html`: High-fidelity work order deployment with multi-skill XP multipliers.
- `jobs.html`: Responsive job board for active contract discovery.

### System Assets
- `manifest.json`: Progressive Web App (PWA) configuration.
- `service-worker.js`: Offline protocol for field-ready reliability.

## ⚙️ Technical Specifications
- **Framework**: Tailwind CSS (CDN).
- **Backend**: Supabase (JS SDK).
- **Payments**: PayPal (SDK Integration).
